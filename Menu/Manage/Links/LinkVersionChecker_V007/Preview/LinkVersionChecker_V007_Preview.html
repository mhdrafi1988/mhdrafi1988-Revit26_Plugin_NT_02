How a cloud link finds its Desktop Connector copy

StepWhat happens
1Take the cloud path after Autodesk Docs://: ALEC Engineering and Contracting LLC/Wynn Marjan Island/Project Files/02 - SHARED/ALEC - DESIGN/…rvt
2Put each Desktop Connector root in front of it, turning / into \. The roots tried are %USERPROFILE%\DC\ACCDocs (Desktop Connector 16+), then %USERPROFILE%\ACCDocs (older versions), then any root set in settings_v007.json. The first root that has the file wins.
3Read the file's Windows cloud-file state and "Date modified" from the folder listing, the same way V006 does for Desktop Connector links. Nothing is downloaded.
4No copy found: On this PC shows No DC copy (dotted icon, counted under Missing / other) and the date shows "—". The link is still listed.

What "Latest from ACC?" shows

LinkStatus partDate and time part
Desktop ConnectorSame as 7.0.0: the loaded copy's save stamp compared with the file on this PC. Yes, Reload needed, Sync pending or Unknown."Date modified" of the file on this PC, which is the latest version Desktop Connector has synced from ACC.
Cloud linkNot checked until you press Check cloud versions. Then ACC answers Yes, Newer in ACC or Unknown, the same as 7.0.0."Date modified" of its Desktop Connector copy, i.e. when the latest version was published to ACC. "—" when there is no copy. The Revit API gives no date for a cloud link by itself.

The hover text on the date says where it came from, e.g. "Latest version in ACC: 06-10-2026 09:36 (Date modified of the Desktop Connector copy, C:\Users\Rafi\DC\ACCDocs\…)".
