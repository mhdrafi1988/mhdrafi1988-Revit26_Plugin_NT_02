Link Version Checker v7.0.0 (V007): design preview

The data is made up and every control works. Click the tiles, change the filters, click a row, right-click a row, or press Check cloud versions. Things marked NEW are not in V006.
  • Cloud links are listed. Links saved as Autodesk Docs://Account/Project/… (and BIM 360://…) get their own rows. V006 left them out, so they only showed up in the "other links hidden" count.
  • New Source column and tiles: Desktop Connector, Cloud link, and Other path (network or local, hidden until you turn on Show other links).
  • Latest from ACC? for cloud links: Check cloud versions asks ACC (GetResourceVersionStatus) and shows Yes, Newer in ACC or Unknown. It only runs when you press the button, so Refresh stays fast and works offline.
  • New ACC project column: shows the project name and whether it is the same ACC project as the open model.
  • New filters: Source, ACC project, Folder, In model and Latest dropdowns, a search that also matches the path, Show other links, and a Clear filters button. Active filters show as chips you can remove one at a time. The filters and the tiles work together.
  • Unchanged from V006: Desktop Connector state, Always keep, Open folder, Reload/Unload, Excel export (new columns added at the end), and the Folder display setting. V006 stays in the Link Check dropdown under V007.
