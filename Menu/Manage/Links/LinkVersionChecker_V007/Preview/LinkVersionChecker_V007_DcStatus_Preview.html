"Not a cloud file" and the green tick icons

What "Not a cloud file" means

The tool asked Windows about the file, and Windows answered that it is a normal file, not a Desktop Connector cloud file. For your files that answer is very likely wrong: Explorer shows the same files with a filled green tick, which means Always keep on this device.

Most likely cause: by default, Windows can hide cloud-file details from ordinary programs like Revit, while Explorer always sees them. When Windows hides them, the tool's main check comes back empty, and 7.1.0 stops at "Not a cloud file". The "Always keep" flag, which is an ordinary file setting, is never looked at.

The icons you want already exist in the tool (filled green tick, green outline tick). They don't show because the status was read wrong. The fix is in how the status is read.

Highlighted: "Not a cloud file" stays as a status, but after the fix it should only appear for a file that really isn't managed by Desktop Connector, e.g. one copied into the ACCDocs folder by hand.

Proposed fix (7.1.1, a bug fix)

  1. Ask Windows to show the cloud-file details for the moment the tool reads each file, then switch back. Windows offers this to programs for exactly this purpose. It affects only that one check, not Revit.
  2. If Windows still gives no answer, read the file's own flags, which ordinary programs can see: "Always keep" set gives Always kept. Space freed or still downloading gives Online only. Neither, with the file fully on disk, gives Available locally, since every file under ACCDocs belongs to Desktop Connector.
  3. Nothing is downloaded, as now: the tool only reads the folder entry, never the file's contents.
  4. The hover text on the status says which way it was read, e.g. "Read from Windows cloud-file state" or "Read from the file's Always-keep flag", so a wrong answer is easy to spot.

To confirm before I code

  1. Keep the icons as drawn here: filled green circle with white tick for Always kept, white circle with green ring and green tick for Available locally. They match your Explorer screenshots.
  2. Ship it as 7.1.1 (plugin 6.10.1), a fix with no new options.
  3. Optional: on the selected row, draw the icons white (as in this preview) or keep them green on the blue.
