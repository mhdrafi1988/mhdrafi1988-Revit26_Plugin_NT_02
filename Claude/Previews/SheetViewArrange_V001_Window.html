Sheet View Arrange v1.5.0

SloperPro plugin 7.19.0 · tool folder SheetViewArrange_V001 · Sheet Place panel, button Arrange Views

Every name, label and number on this page is a static mock-up with sample data — no real project or client content.

What is new — the layout was fixed before 1.4.0: rows spread to the full width, rows spread to the full height, views on a common bottom line. 1.4.0 turned that into three choices — Across the width, Down the height and Align views in row — where left, right, top and bottom pack against the margins you set, at the minimum gaps. 1.5.0 adds a fourth, Flow: the order can wrap down columns (top to bottom, then across) instead of across rows. The reading order (Detail Number) is never changed by any mode. Rows + Auto + Auto is the default and reproduces the pre-1.4.0 layout exactly, so settings saved by an earlier version look the same as before.

The layout modes New

The same five sample views (three 180 × 95 details, two 180 × 190 sections) in the same reading order, with the same margins and 20 mm minimum gaps. Only the Layout choices differ. The last two tiles show column flow, where the order runs down each column instead of across each row.

Auto + Auto Default

Exactly the pre-1.4.0 layout: full rows spread to the width, rows spread to the height, short last row per Last row.

Left + Top

Packed in both directions against the top and left margins — a compact block, the rest of the sheet left clear.

Left + Bottom

Rows start at the left margin and the block sits on the bottom margin, so free space collects at the top.

Right + Bottom

Every row ends on the right margin, next to the title strip; the short last row ends there too.

Centre + Centre

Packed and centred both ways, with Align views in row on the centre line instead of the bottom line.

Justify + Spread, top line

Every row is spread to the full width, the last row included, and views of differing height hang from a common top line.

Columns + Auto New in 1.5.0

The order runs down each column, then across. Auto spreads the full column over the height and the columns over the width; the short last column packs from the top at the gap the column before it used.

Columns + Top + Left New in 1.5.0

Packed at the minimum gaps against the top and left margins: each column fills from the top, the columns run from the left.

Behaviour notes

  • The order is untouched. Views are still sorted by Detail Number in natural order (1, 2, 10 … A1, A2, B1). No mode re-orders, resizes, rescales or removes anything — viewports are only moved. Flow changes the direction the order runs, not the order itself.
  • Column flow swaps the two placement roles. Across the width places the columns across the width and Down the height places each column’s views down the height. A column wraps when the next view won’t fit at the minimum row gap, and Last row places the short last column.
  • The grid follows the flow. In column flow the band column, its filter and the Rows count read Column / Columns, and grouping by layout band groups by column.
  • The margins define everything. Left / right / top / bottom pack against the usable area, which is the title block inset by the four margins, so nothing crosses the title strip.
  • Auto is the default. Settings files written before 1.4.0 load unchanged and keep the old look. The file is now format version 4: version 3 added Horizontal, Vertical and RowAlign in 1.4.0, version 4 adds Flow and ColumnAlign in 1.5.0, and every new field defaults to the behaviour of the version before it.
  • Last row applies to Auto only, and is greyed out for the other modes — they treat every row alike.
  • Overflow still blocks Apply. If a row is wider than the usable area, or the rows need more height than it has, the plan reports what is short and nothing moves — an over-wide row or over-tall block is drawn from the left and top edges so the overflow is visible on one side.
  • Unchanged: pinned views (moved and re-pinned, or skipped), views owned by another user or changed in central are skipped and reported, one Undo step, Apply refused if the sheet changed after the preview.
