How the category loader works

PartBehaviour
Look inTick the host and any loaded links. Links that are not loaded are not listed.
CategoriesStarts with Doors, Walls, Plumbing Fixtures and Pipe Accessories. + Add category searches as you type and lists only categories that have elements in the ticked models. The model's full category list is never shown.
Load typesReads only the chosen categories from the ticked models, then fills each row's Type list and the Found counts.
MemoryModels (by link name), categories, mapping rows and placement modes are saved to %AppData%\Revit26_Plugin_Revised\WetAreaWaterproofing\settings_v003.json, which has a Version field. On its first run, V003 copies your V002 settings into it.

The other steps

StepWhat changed in 3.0.0
1 · Find roomsThe room grid as in V002. The rooms that need attention and the boundary repair settings now sit beside it; V002's separate "Check outlines" step is gone.
2 · RoofUnchanged: roof type, workset, offset above slab, Comments.
3 · MappingNew, shown above. Plan, section-view and callout settings moved into its Views card.
4 · Review & runThe Review table (its columns now read Mapping row and Place as). After the run the result and the Excel report card take its place.

First run: V003 reads V002's settings and turns its section targets into mapping rows. Like V002, the drain row finds drains in Pipe Accessories and Plumbing Fixtures. An element can match several rows, so a "Shower Drain" fixture gets a drain cut and a shower cut; untick one in the Review if you want only one.
