Annotation Overlap Report NEW TOOL

Preview of tool 1.0.0, plugin 7.5.0. A separate tool from Annotation Overlap Detection: it scans a batch of views and sheets, checks every annotation type it finds, and lists each overlapping pair. It reports only and changes nothing in the model.

Sample data. No real project names. Everything on this page is new in 1.0.0.

2. Main window, after a run

Modeless, so Revit stays usable while it is open. The type list shows every annotation type found in the scope, with its count. Grids, levels, section, elevation and callout marks and view titles are listed greyed out and are not checked yet. Selecting a row and pressing Zoom to pair opens that view and highlights both annotations.

3. Known limits in 1.0.0

Boxes are Revit's bounding boxes: a tag's box includes its leader, and a dimension's box includes its witness lines. Annotations inside linked models, and overlaps between two viewports on a sheet, are not checked.

4. Excel export

Export to Excel saves the listed pairs to one .xlsx file, one row per overlapping pair, using the current Show filters. You choose the file name and folder. A second sheet, Run info, records the tool version, counts and any skipped views.
