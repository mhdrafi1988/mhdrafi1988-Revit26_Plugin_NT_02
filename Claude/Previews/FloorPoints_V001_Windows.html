Floor Points tools NEW IN 6.33.0

Floor versions of every Shape Points tool, on a new Floor Points panel. Each window is the roof tool's window with floor wording; floor-specific parts are marked in green. Every tool refuses floors that are in a group, borrowed by another user, in a read-only model, or that can't be shape-edited. All values are sample data, not a real project. On a narrow screen, scroll each window sideways.

1 · Ribbon: new Floor Points panel next to Shape Points NEW

One plain button per tool (each has one version), stacked 3 + 3 + 1. The buttons reuse the roof icons for now.
