Section Roof Detail Lines — v1.1.0 (build V001) Open a sheet: lists every element its sections show, from the host model and from each loaded link, then traces the cut profile of the roofs you tick and draws a line on the walls beside them, in the sections themselves. Up to 10 sections in one run, one Undo step.

What is new in 1.1.0

  • Sides to draw — Top, Bottom, Left, Right, all four ticked by default, so the tool draws exactly what 1.0.0 drew until you change it. Unticking the last one puts it back. To get just a line under each roof, leave Bottom. new
  • Wall face to draw on — Nearer the roof (the default, as in 1.0.0), Both faces, Left, Right. Replaces the Line on both faces tick box; a 1.0.0 settings file with it ticked opens on Both faces. new
  • A side is where the material is. Each edge is probed 0.3 mm either way against the cut face: the probe that lands on the face is the solid side, so the other way is out, and that direction gives the side. Bottom is therefore the underside on a flat, sloped or stepped roof alike, and the head of an opening the section passes through reads as Bottom too — that is the surface you see from under it. new
  • Left and Right are on screen in that section, so a section looking the other way puts them the other way round. Nearer the roof is the wall choice that does not depend on which way the section faces.

From 1.0.0

  • The tool itself — nothing in the suite listed what a section shows, and nothing drew in a section.
  • Host model and links together. The host model is read with Revit's own view-bound collector, so the crop, far clip, visibility/graphics, view filters and hand-hidden elements all count. A link has no such query, so its elements are tested geometrically against the same crop box — generous on purpose, so a roof the user can see is never dropped in silence.
  • Roof line = the cut profile. The section is cut on the view's own plane, and the face that leaves coplanar with it gives the edge loops — outer loop and any opening the section passes through — already in the plane a detail curve needs.
  • Wall line = full visible height. One vertical line per chosen face of the wall's cut profile, over the wall's own height in the section, held inside the crop, and only where the wall comes within the adjacency tolerance of a ticked roof.
  • Run scope. Every section on the active sheet, capped at 10. A section open on its own is offered by itself.
  • One Undo. Every section's lines are created in one transaction inside one transaction group, assimilated. A cancel rolls the whole run back.
