  • new OPENING CLEARANCE: one row per MEP category and size range. An empty Size from means 0, an empty Size to means no upper limit (rule 4). Size is the diameter for round MEP and the larger side for rectangular.
  • Applies: Each side gives size + 2 × offset, Total gives size + offset. Example works the rule out for its largest size, with Round up to applied.
  • Default offset is used for every element no rule covers. A first run has no rules, 50 mm each side, 50 mm overshoot and no rounding.
  • Save rules writes %AppData%\Revit26_Plugin_Revised\VoidOpenings\settings.json; the rules are back the next time the tool opens. Revert drops unsaved changes.
  • Each model list holds (Active model) first, then every Revit link by name. One model per side.
  • A category with no elements shows Empty and cannot be ticked. Ticks are kept when you press Refresh.
  • Stairs, Landings and Ramps show "Marker only, no cut" once ticked.

What the columns and states mean

  • Status: Detected → Generated (void placed) → Cut (cut verified), or Failed / Rejected / Review.
  • Tracking (re-runs): New, Existing, Updated, Manually modified, Source deleted.
  • Width and Height are for rectangular openings, Diameter for circular ones. All sizes in millimetres.
  • Messages appear in the strip above the status bar, not in pop-up dialogs.
