NEW Select All / Select None sit above the link list and act on the rows currently shown (search and status filters respected). After “Load all links”, Select In View ticks only the links visible in the view. The count line reads “selected · in view · shown”.

How it behaves

Opening NEW
  • Lists only loaded links that are visible in the active view (not hidden, category on, link in the view’s range).
  • Ticks them all, as today, so a normal run is unchanged.
  • Builds the element tree for those links only.
Load all links NEW
  • Adds the remaining loaded links, unticked, tagged “Not in view”.
  • Keeps your search text, sort and ticks.
  • “Current view only” or “Refresh from view” returns to the short list (e.g. after you switch view).
Unchanged
  • Unloaded, not-found and closed-workset links stay out of the list.
  • Settings files, mapping, output and the “Restrict to boundary” scope.
Load all linksAdds every loaded link in the project to the list, including the ones not visible in “Level 2 – Floor Plan”. They stay unticked until you tick them.
