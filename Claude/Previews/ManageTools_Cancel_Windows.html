Manage Tools: Esc / Cancel NEW

Every Manage Tools tool now cancels a running step. Esc, or the Cancel button in the status strip, asks for confirmation. Yes stops the run and undoes the model changes it made. No carries on. Esc works while Revit is the foreground application. Tools without a window show a small progress pop-up with the same Cancel button. Sample data: names are made up.
