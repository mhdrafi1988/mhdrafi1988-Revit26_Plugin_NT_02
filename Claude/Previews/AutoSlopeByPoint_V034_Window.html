Auto Slope By Point 34.0.0 (V034)

New version next to V033, released in plugin 6.49.0. It adds three Path options that control the check that each path link stays on the roof surface. The defaults are V033's fixed values, so results only change when you edit them.

Sample data. The roof, numbers and log lines are made up for this preview.

What V034 adds

  • Path check spacing (mm): distance between the on-roof checks along each link. 10–2000 mm, default 76.2 mm (V033). Every link still gets at least 10 checks.
  • Projection tolerance (mm): height margin when a point is matched to the roof top face. 0.1–50 mm, default 1 mm (V033).
  • Exact segment test (off by default): also checks each link against the roof outline and every opening edge, so a gap of any width is caught. Slower on big roofs.
  • All three are saved in settings.v034.json, shown in the path graph log line and written to the Excel Run Summary.
  • Includes V033 33.1.0: Esc or Cancel while a run is going asks Yes / No, and Yes rolls the roof back.
