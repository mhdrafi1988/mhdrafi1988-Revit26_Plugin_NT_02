Auto Slope By Point 34.0.0 (V034)

Plugin 6.47.0. New version next to V033. It adds one option: the sample spacing for the check that keeps water paths on the roof.

Sample data. The roof, numbers and log lines below are made up for this preview.

What changed

  • Sample spacing combo box in Path & curves: 40, 50, 75 (default) or 100 mm.
  • 75 mm is what V033 uses, so the default gives the same slope as V033. 40 mm finds narrower openings and takes about twice as long on the path graph step.
  • The section summary shows the spacing, and the Custom tag appears when it is not 75 mm.
  • The log line for the path graph and the Excel Run Summary show the spacing used.
  • By Point V034 is first in the By Point pulldown. V033 is unchanged below it.
