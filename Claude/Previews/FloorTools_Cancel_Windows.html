Floor Tools: Esc / Cancel NEW

Every Floor Tools window now cancels a running step. Esc, or the Cancel button in the status strip, asks for confirmation. Yes stops the run and undoes the model changes it made. No carries on. Esc works while Revit is the foreground application. Sample data: floor names are made up.

1. Window while a run is in progress (example: Floor Slope By Drain 1.1.0)

The Cancel button appears in the status strip and the rest of the window is disabled. The former footer Cancel button is gone.
