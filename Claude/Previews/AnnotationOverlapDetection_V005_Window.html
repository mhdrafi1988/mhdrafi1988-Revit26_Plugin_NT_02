How a resolve works

  • "Up" means up on screen, along the view's up direction, so rotated plans work too.
  • Distance moved = vertical overlap of the two boxes + the clear gap.
  • Text notes, tags and room tags move as a whole. A tag's head moves and its leader stays on the host. For a dimension, only the text moves.
  • Pinned elements, elements in a group and elements owned by another user are skipped, and the Status column says why.
  • All moves in one run are one transaction, so one Undo reverts the run. The view is re-scanned afterwards, and any new clash a move created shows up in the grid.
  • Mode and gap are remembered for next time.
