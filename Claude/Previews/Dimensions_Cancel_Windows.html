Dimensions: Esc / Cancel NEW

Every Dimensions tool now cancels a running step. Esc, or the Cancel button in the status strip, asks for confirmation. Yes stops the run and undoes the model changes it made. No carries on. Esc works while Revit is the foreground application. Tools without a window show a small progress pop-up with the same Cancel button. Sample data: names are made up.

1. Window while a run is in progress (example: Auto Dim Detail Line 10.2.0)

The Cancel button appears in the status strip and the rest of the window is disabled.
