EPS Tapered Insulation Layout NEW — DESIGN

Tool window mock-up for the EPS Tapered Insulation Layout tool. The user selects a footprint roof with shape editing (sloped to drain), and the tool fills the area with 1200×1200 mm stepped EPS roof panels (100 mm base + stacked 35 mm layers) to approximate the slope. All values below are sample data, not a real project.
