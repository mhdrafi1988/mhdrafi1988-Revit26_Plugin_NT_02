Sheet Text Replace v1.4.0 · plugin 7.30.0

The tool now works in a single view as well as on a sheet. Press the button in a plan, section, detail, drafting view or legend and it asks whether to work on that view alone; the picker in the window lists every sheet and every view that can hold text notes, so the scope can be changed without reopening. Working on a sheet is unchanged. Sample data: sheets, views and notes are made up.

What changed in 1.4.0

  • A single view is now a scope of its own. The notes shown in that one view are searched and replaced, whether or not the view is placed on a sheet.
  • Started from a plan, section, elevation, detail, drafting view or legend, the tool asks "Work on the active view alone?" — Yes loads that view, No opens the window with nothing picked, Cancel closes it. Started on a sheet, nothing changes: the sheet is loaded as before, with no question.
  • The picker lists sheets and views, so the scope can be changed at any time without reopening the tool. Its label is now Sheet or view, and the card is Scope & Views.
  • In a single-view scope the Views list holds that one view, ticked, and its notes stay ticked even when the view is on sheets — the sheets it is on are reported in the log instead ("a change here shows on those sheets too"), because you picked that view on purpose. On a sheet, views shown on other sheets still start unticked.
  • A model with no sheets can now be used: only a model with neither sheets nor text-capable views is refused.
  • Everything else is unchanged — the same preview, Found text, Recent searches, one undoable transaction and the same skip reasons (owned by another user, in a group, read-only, changed since preview).

Earlier, in 1.3.0

  • Search kept for next time: Find, Replace with, Prefix, Suffix and the four options are saved when the window closes and after Apply, and filled in again when the tool opens, even after Revit is restarted.
  • Recent ▾ on the Find & Replace card lists the last 10 searches. Click one to reuse it; Clear list forgets them.
  • Saved in %AppData%\Revit26_Plugin_Revised\SheetTextReplace\settings.json.
  • Fixed: a second request sent before Revit ran the first (for example a quick double-click while a sheet was loading) no longer replaces the first one and leaves the window busy; it is refused with a message in the log.

Earlier, in 1.2.0

  • Found text area under the preview grid: click a row and every line of that note shows, with its view, line count and character count. Select part of it and press Ctrl+C, or use the buttons.
  • Copy text: the whole current text of the picked note. Copy new text: the whole text after Apply. Copy all found: every note in the preview, separated by a blank line.
  • Copy full text on the right-click menu of each preview row.
  • Each copy is written to the Activity Log. Copying only reads; the model does not change.
