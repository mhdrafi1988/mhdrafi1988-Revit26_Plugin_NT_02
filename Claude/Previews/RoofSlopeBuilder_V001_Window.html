What changed from the 1.0.0 draft

  • Heights are measured from each drain's outline, so square and long drains no longer leave a flat strip beside them.
  • Every number box is checked on Apply. A wrong entry is named instead of quietly replaced.
  • Roofs that can't be sloped are listed in the window (group, read-only, slope-defining edges, borrowed).
  • A roof whose type has no Variable layer is flagged. The drains grid shows each opening's centre.
  • Options are remembered for next time.
