Roof Tools: Esc / Cancel NEW

Every Roof Tools window now cancels a running step. Esc, or the Cancel button in the status strip, asks for confirmation. Yes stops the run and undoes the model changes it made. No carries on. Esc works while Revit is the foreground application. Sample data: roof and view names are made up.

1. Window while a run is in progress (example: Roof Points & Slope 1.2.0)

The Cancel button appears in the status strip and the rest of the window is disabled. The former “Cancel Run” footer button is gone.
