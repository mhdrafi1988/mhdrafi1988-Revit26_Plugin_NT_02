Detail Line Closed Loop v3.0.2

Plugin 6.37.1 · Error handling fix. The window layout is unchanged; what changed is what you see when a Revit action fails unexpectedly.

Sample data: element ids, lengths and the error text are made up.

What changed in 3.0.2

  • Title bar and header show v3.0.2.
  • An unexpected error in Select Detail Lines, Run, Delete Selected or Refresh still adds an Error line to the Processing Log.
  • NEW It now also shows the standard SloperPro error dialog and is written to the error log file. Before, only the log line appeared.
  • Cancelling a pick (Esc) is not an error: it logs "Selection cancelled." and shows no dialog.
