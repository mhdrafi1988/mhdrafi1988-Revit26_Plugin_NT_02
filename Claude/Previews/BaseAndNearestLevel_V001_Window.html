Base and Nearest Level — v1.0.0 (build V001) Roofs, floors and walls only. Reads each element's base level and offset, finds the project level nearest to its real base elevation, and writes four parameters: base level name, base offset, nearest level name, nearest offset. Offsets are Length parameters, so schedules sort and total them. A separate action can re-host ticked elements onto their nearest level without moving them.

6 · Still open

Three decisions left before this gets built. Everything else above is settled.

  • Shape-edited floors and roofs on re-host OPEN — shown above as skipped, with an “include” tick, because changing a floor's or roof's Level can reset its point edits. The alternatives are to re-host them like anything else, or to exclude them with no override. Writing the four parameters always covers them either way.
  • Scope of 1.0.0 OPEN — this page shows both actions in one release. The alternative is parameters in 1.0.0 with no model change anywhere in the tool, then re-host in 1.1.0.
  • Go-ahead OPEN — nothing is written until you confirm.

Settled: nearest level defaults to closest in either direction with all three rules selectable; offsets are Length parameters; this is a new tool beside Base Level to Parameter; re-host is a separate opt-in action.
