Base and Nearest Level — v1.1.1

Static mock-up of the shipped tool, in the state that shows the change. New in 1.1.0: any level-based model element, in three tiers, with a searchable Categories grid. All numbers, level names, element ids and family names below are sample data — not a real project.

T1 level + offset from it

Walls, floors, ceilings, roofs, structural columns and framing, MEP curves, stairs, families placed on a level. Z = level elevation + offset holds, so all four parameters are written and the element can be re-hosted.

T2 offset from the host

Doors, windows, face-hosted families. "Offset from Host" is measured from the host face, not the level, so the two level names are written and the two offset slots are left empty. Never re-hosted.

T3 level only

A read-only Schedule Level with no offset to measure. Same as Tier 2: level names written, offsets left empty, never re-hosted.

Base and Nearest Level — v1.1.1 (build V001) Any level-based model element. Reads each element's base level and offset, finds the project level nearest its real base elevation, and writes four parameters: base level name, base offset, nearest level name, nearest offset. Offsets are Length parameters, so schedules sort and total them. A separate action re-hosts elements onto their nearest level without moving them.

7 · As built

1.1.1 — fix only: the window failed to open with “Set property Style threw an exception” because the Activity Log border pointed its Style at a colour. It now opens; nothing looks different.

1.1.0

  • Any level-based model element, read in three tiers. Tier 1 (level + an offset measured from it) gets all four parameters and can be re-hosted. Tier 2 (offset from the host) and Tier 3 (level only) get their two level names, with the two offset slots left empty, and are never re-hosted.
  • The default scope is unchanged: the window opens on Roofs, Floors and Walls, so the same button does the same thing as 1.0.0. Widening is one click — hence a MINOR bump, not a MAJOR one.
  • Categories are discovered, not hard-coded. The grid lists whatever the load found, with per-tier counts, a search box and presets. The ticked set is remembered between sessions.
  • The four parameters bind to the ticked categories only, not to every level-based category, so they do not appear on the whole model.
  • Re-host is Tier 1 only. Tier 2 and Tier 3 are hard skips with no override tick. Shape-edited, grouped, read-only and checked-out elements are skipped as before.

1.0.0

  • Nearest level defaults to closest in either direction, with all three rules selectable. Ties go to the lower level.
  • Offsets are Length parameters, so they follow the project's unit display and total correctly in a schedule.
  • A new tool. Base Level to Parameter stays at 1.4.1 and keeps writing its single combined text value.
  • Re-host is a separate opt-in action behind its own confirmation dialog, in one undo step.
