Workflow

Find roomsRead rooms from the host model and every loaded link
Flag wet areasMatch room names against keywords; you tick or untick
Waterproofing roofFind the slab under each room and place a roof from the room boundary on the slab top (or level + offset if there is no slab)
Plan per roomA cropped floor plan per room (crop = room + margin)
Up to 6 reference sectionsAt the full room, doors, drains, wall corners, WC, shower. One per item or all matches; one drafting view for all or one per target CHANGED
SheetsOne sheet per room or group, or packed. Title block from your list (A0 first); fit check at the chosen scale CHANGED
Print setA View/Sheet Set of the new sheets

Each step runs in its own transaction; run all of them, or only some (see “Run steps” at the bottom of the window). Rooms whose slab or elements are checked out by another user are skipped and listed in the log.
