Wet Area Waterproofing v2.2.0 · V002

V002 is V001 (v1.2.5) with a new way to assign drafting views in 4 · Section targets: you can now type and search instead of scrolling a long list. Rooms, roofs, plans, sections and the Excel report work as before. Both versions sit in one ribbon pulldown and share settings, tags and reports. Every view, sheet and room name on this page is sample data.

NEW in 2.2.0 The window is six steps with a Review table: see every roof, plan and section, untick any single one, then Create. Nothing is created before that.

NEW in 2.1.0 The Mode list has two more choices, Section (makes a section view) and Ref. Callout (points to a drafting view), with a new Section settings block. FIXED in 2.1.0 A second run no longer adds a second callout for the same room; a callout or section view you have drawn in is kept.

Six steps and a Review NEW in 2.2.0

One step is open at a time; finished steps fold into one green line with Change. Step 2 (Check outlines) is skipped when every ticked room's outline closed. Step 4 has Run without review for repeat runs. The settings below in "Layout 1", "Layout 2" and "Mode list" are now inside step 4.

Layout 2 · “Assign drafting views” picker panel NEW

This is the alternate layout. It assigns every target from one screen: targets on the left, all drafting views in a table on the right. Pick a target, then double-click a view or press Enter. The next target is selected for you, so four targets take four double-clicks. Use as new name points the target to the typed text. Both layouts edit the same values, so you can switch between them freely.
