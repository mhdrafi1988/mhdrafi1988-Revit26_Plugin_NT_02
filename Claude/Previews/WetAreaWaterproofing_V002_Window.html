Wet Area Waterproofing v2.0.0 · V002

V002 is V001 (v1.2.5) with a new way to assign drafting views in 4 · Section targets: you can now type and search instead of scrolling a long list. Rooms, roofs, plans, sections and the Excel report work as before. Both versions sit in one ribbon pulldown and share settings, tags and reports. Every view, sheet and room name on this page is sample data.

Layout 1 · Search in each “Points to” box NEW

The editable list is now a search box. Typing A-501 drops down the matches; ↑/↓ move, Enter or a click picks, Esc closes, and ⏷ lists every view. The grey line under each box says where the view is, or that it will be created.

Layout 2 · “Assign drafting views” picker panel NEW

This is the alternate layout. It assigns every target from one screen: targets on the left, all drafting views in a table on the right. Pick a target, then double-click a view or press Enter. The next target is selected for you, so four targets take four double-clicks. Use as new name points the target to the typed text. Both layouts edit the same values, so you can switch between them freely.
