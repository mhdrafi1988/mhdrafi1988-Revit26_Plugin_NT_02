DWG Tools

The four, side by side

All four act on the same DWGs, so each icon has to say which one you are about to run.

DWG To DL(P)

Turns a DWG into detail lines. Keeps the icon it had — it is the one the other three were borrowing.

Export DWG NEW

Writes the CAD links and imports out to a folder. A drawing with an arrow leaving it.

DWG Manager NEW

Lists every CAD link and import so you can review and delete them. A drawing with a tick against it.

DWG Statistics NEW

Counts DWG usage across the project. A bar chart on the drawing.

Style

These follow the panel they sit on: a full‑bleed #2E6E91 tile, white for the drawing, #F4A72C for what that tool does to it. That is what 81 of the suite's 120 _32.png icons use, and 30 of those already carry a warm accent. Each size is drawn as whole pixels at that size rather than shrunk from the other, so the 16 px version stays crisp — which is the size that actually shows here, since all four are stacked buttons.

The monochrome brief at the top of Claude/LOGO PROMPT FOLDER/Icon_Prompts.md describes an earlier direction the shipped set never adopted; that is noted there and in RIBBON_AND_ICONS.md.
