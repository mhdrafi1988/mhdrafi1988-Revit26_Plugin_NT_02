5 · Decisions

1.3.0 · clear old values NEW
  • Third Existing values option: Clear old values, write only new values. Every ticked element ends up with only its new value.
  • Different values are rewritten whatever the row choice says (the If value exists column and buttons are disabled); an old value on an element with no base level is cleared (empty).
  • Only ticked elements are touched. Elements owned by another user, read-only, in groups or out of date are still skipped, values and all.
  • Skip stays the default; the option is not remembered. “Skip these” in the dialog keeps every old value, cleared ones included.
1.2.0 · existing values
  • “Overwrite existing values” (checkbox) becomes Existing values: Skip / Rewrite. Skip stays the default, as before, and is still not remembered.
  • Each row with a different existing value can override the default (Default / Skip / Rewrite). Choices survive Re-check and format changes; loading a new element list resets them.
  • An element whose value already equals the new one stays “Up to date” and is never rewritten, whatever the choice.
  • Run asks before replacing any value (Rewrite / Skip these / Cancel) and logs each old → new value. Rewritten rows show “Assigned · rewrote value”.
Suggestions for later
  • Export the old values to CSV before a rewrite, as a backup outside the Revit undo stack.
  • “Rewrite only values this tool wrote” — rewrite values that match a known pattern (e.g. “Level 02 (+300)”) and keep hand-typed ones (“L2”).
1.1.0 (confirmed by the owner)
  • Value format: Level name only, or Level name + offset with all 8 patterns of 2a (Custom… included). The choice is remembered.
  • Same value already present → "Up to date", never rewritten (new Up to Date tile).
  • New Value green when changed, grey when the same; "Changed only" filter.
  • Metric tiles filter the grid; Select in Revit and Zoom to; Load Selection; Tick all / Untick all per category; Base Level tooltip shows the source parameters.
From the brief
  • All five level-source rules are supported (walls, columns, floors/roofs, families, MEP).
  • No base level → the row stays ticked, is skipped and logged as a warning.
  • New parameters are shared, instance, Text, schedulable, bound to the ticked elements' categories.
  • Missing categories on an existing parameter are added automatically (Warning, not Blocked).
  • Offset in mm, signed, whole millimetres, zero = “(0)”. Existing values are skipped by default.
  • Run (and Close) are disabled while a run is in progress.
Confirmed by the owner
  • Button on the Coordination panel; folder Menu/Coordination/Parameters/.
  • Summary counts ticked elements; a blocked check marks every ticked element Blocked.
  • “Load Active View” kept, to go back after “Load All Model Elements”.
  • Offset always in mm; new parameters always go under Data.
  • New parameters allow different values per group instance, so grouped elements can be written.
