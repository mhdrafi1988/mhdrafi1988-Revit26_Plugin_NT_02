5 · Assumptions and open questions

Assumptions shown above
  • All five level-source rules are supported (walls, columns, floors/roofs, families, MEP).
  • No base level → row stays checked, status Warning, skipped, logged.
  • New parameters are shared, instance, Text, schedulable; bound to the checked elements' categories.
  • Missing categories on an existing parameter are added automatically (Warning, not Blocked).
  • Offset: mm, signed, rounded to whole mm, zero = “(0)”.
  • Overwrite existing values: off by default, so those rows are skipped.
  • Run is disabled while running; Close too.
  • Pre-checks refresh automatically; “Re-check” also available.
