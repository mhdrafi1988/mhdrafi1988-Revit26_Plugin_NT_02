View Auto Renamer 7.2.0 NEW: Esc / Cancel

Pressing Esc, or clicking Cancel in the status strip, while a run is in progress asks for confirmation. Yes stops the run and, for a rename, undoes every rename of that run. No carries on. Esc works while Revit is the foreground application. Sample data: view names are made up.

1. Window while "Commit selected" runs

The Cancel button appears in the status strip. Everything else is disabled until the run ends, so a second run cannot start.
