2. Load by type NEW

Click "Load by type", tick the view types you want, then "Load ticked types". Only those views are read from the project. A type that is already loaded is greyed and marked "loaded". Legends have no class of their own in Revit, so loading them reads all views.

3. Group headers NEW

One header per view type that has views, with a count, in the order of the filter popover: Sections & Callouts, Floor Plans, Ceiling Plans, Structural Plans, Area Plans, Elevations, Drafting Views, Legends, Schedules. These are the groups the duplicate check uses. Click a header to fold or unfold the group; "Expand all" and "Collapse all" do every group. The header checkbox ticks every view listed in the group, unticks them when all were ticked, and shows a dash when only some are ticked. Clicking a column header sorts inside each group. Untick "Group by type" for the flat list of 7.2.0; the choice is saved.

4. Rename panel, unfolded NEW

Unfolded is the default, as in 7.2.0. Click "RENAME OPTIONS" to fold it to the one bar shown in section 1; the list takes the freed height. The choice is saved.

Plugin change

Tool version 7.2.0 → 7.5.0, plugin 6.52.0 → 7.0.0. Fixed: the footer button "Reset all names" now resets every row; it reset only the ticked rows.
