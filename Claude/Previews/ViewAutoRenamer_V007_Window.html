2. Group headers NEW

One header per view type that has views, with a count, in the order of the filter popover: Sections & Callouts, Floor Plans, Ceiling Plans, Structural Plans, Area Plans, Elevations, Drafting Views, Legends, Schedules. These are the groups the duplicate check uses. Clicking a column header sorts inside each group. Untick "Group by type" for the flat list of 7.2.0; the choice is saved. After "Load all views" the whole project is grouped the same way.

3. Log, minimised and expanded NEW

Minimised (every time the window opens): one bar with the line count and the latest line in its colour, so a warning or error still shows.
