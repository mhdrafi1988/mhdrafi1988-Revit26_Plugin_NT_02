With "Stop and undo everything", the first failure rolls back the whole run and this dialog names the view and the reason; nothing on either sheet changes. Unexpected errors are also written to %AppData%\Revit26_Plugin_Revised\Logs.

How it behaves

  1. Sheet 1 is the active sheet when you start from a sheet view. Start from any other view and Sheet 1 is empty until you pick one. Picking a sheet reads it straight away.
  2. The grid lists every placed view on both sheets, grouped by sheet, then by view type. Rows and group headers carry the sheet's colour: blue for Sheet 1, amber for Sheet 2.
  3. The target can be Sheet 1, Sheet 2, any other existing sheet, or a new sheet (number, name, titleblock).
  4. Ticked views from other sheets are taken off their sheet and placed on the target. Unticked views already on the target either stay in place (packing works around them) or are re-packed too; you choose.
  5. Ticked legends are copied: the original stays, and the copy goes on the target at the exact same location it has on its own sheet. If that spot is taken by a view that stays in place, the legend is still placed there and a warning is logged.
  6. Layout uses the Sheet Placer packing (margins, gaps, reading order). Views that do not fit go to continuation sheets.
  7. If a view fails: skip it and report it (default), or stop and undo everything. Expected problems (checked out by another user, view in a group, view already on another sheet that Revit will not release) get a plain reason. Unexpected errors are caught, reported, and logged; nothing reaches Revit unhandled.
  8. The whole run is one Undo step. Schedules are not moved in V001. There is no option to delete a sheet that ends up empty.
